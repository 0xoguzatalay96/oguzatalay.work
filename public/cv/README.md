# Oğuz Atalay CV Repository

This folder contains the canonical master CV files and ATS-standard documents for **Oğuz Atalay** ([oguzatalay.work](https://oguzatalay.work)).

## Files

- `Oguz_Atalay_Master_CV.docx`: Canonical master CV in Word DOCX format.
- `Oguz_Atalay_ATS_Harvard_CV_2025.docx`: Microsoft Word (DOCX) version for corporate ATS screening systems.
- `Oguz_Atalay_ATS_Harvard_CV_2025.pdf`: Harvard ATS standard formatted PDF resume.
- `Oguz_Atalay_Master_CV.pdf`: Direct PDF export of the Master CV.
- `Oguz_Atalay_CV.md`: Canonical master CV in English (Markdown format).
- `Oguz_Atalay_CV_TR.md`: Canonical master CV in Turkish (Markdown format).
